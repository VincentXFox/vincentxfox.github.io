Что строю

OMP Pocket приватный Пульт для парка агентов omp с телефона. PWA на React + шлюз на Bun (реестр сессий, вложения, поиск, пуши, автономные задачи); E2E-релей на AES-256-GCM; рантайм панелей терминалов с эмуляцией экрана и восстановлением после рестарта; движок обновлений, который проверяет SHA-256, ставит атомарно и сам откатывается, плюс chaos-набор на сценарии отказов. 42 тысячи строк TypeScript (52 с учётом стилей), 30 тестовых файлов.
my-cinema приватный Клиент для Android TV на Kotlin — модульный Gradle (core / feature / app), свой слой дизайна, бенчмарки до работы над фичами.
фид каталога приватный Python: каталог на 2 161 товар обойдён, отфильтрован и собран в строгий YML-фид для Яндекс Директа — цена, наличие, категория и минимум четыре фото на белом фоне у товара; плюс отчёт отбора, где назван повод отсева каждого товара.
домашний хостинг VPS на Debian + мини-ПК на Ubuntu: nginx-край со SNI-роутингом, юниты systemd, mesh на WireGuard/ZeroTier, свой RustDesk, llama.cpp с локальными моделями для агентов.
